## Work law — VERIFIED

The v0.7 Habitat UI explicitly states:

`INPUT -> OWNER -> WORK -> OUTPUT -> REVIEW -> HARVEST -> MEMORY`

and:

> A job cannot become DONE until the system checks for a reusable part and a process improvement.

Current `docs/ECOSYSTEM.md` preserves the same lifecycle and adds the crucial clarification:

> The lifecycle is a quality model, not a requirement to simulate several agents.

It also mandates two harvest questions after work:

1. Did we learn a better process?
2. Did we create or improve a reusable Part?

It says not to manufacture harvest artifacts merely to make a run look productive.

## Exact critter contracts — VERIFIED

Recovered from the v0.6/v0.7 source and still present in current `apps/private-hq/client.js`.

### Echo — Chief of Staff / Router
- Eats: goals, evidence, exceptions, approvals.
- Produces: priorities, routed work, decisions.
- Authority: route and approve within human-set authority.
- Limit: cannot invent the mission or silently override Shannon.
- Stop: escalate material conflicts or irreversible choices.
- Waste: Squirrel remembers decisions.

### Owl — Research Scout
- Eats: endgame goals, unknowns, research requests.
- Produces: evidence packets, options, sources, unanswered questions.
- Authority: research and compare.
- Limits: no builds, no spending, no priority changes.
- Stop when evidence is sufficient for a decision.
- Waste: Beetle/Squirrel preserve useful research.

### Beaver — Builder
- Eats: Echo-approved work orders.
- Produces: code, prototypes, tests, docs, reusable modules.
- Authority: modify designated working builds.
- Limits: no self-assigned mission or production deploy without approval.
- Stop: return BLOCKED rather than expanding scope.
- Waste: Beetle decomposes; Parts Bin harvests.

### Beetle — Decomposer / Maintainer
- Eats: failures, stale code, duplicates, abandoned work.
- Produces: cleanup proposals, salvage, technical-debt reports.
- Authority: inspect all; non-destructive maintenance.
- Limit: no silent destructive deletion.
- Stop: request approval before irreversible cleanup.
- Historical source note: **"Goat later handles true retirement."**
- Goat is referenced but no implemented Goat worker has yet been recovered.

### Hawk — Systems Monitor
- Eats: telemetry, queues, failures, costs, retries.
- Produces: health reports, bottlenecks, anomaly alerts.
- Authority: observe and flag.
- Limit: does not fix or redirect work itself.
- Stop: escalate severe health/security conditions.
- Waste: Jane interprets behavior; Echo routes fixes.

### Jane — Field Ecologist
- Eats: behavioral record of critter interactions.
- Produces: handoff observations, niche conflicts, emergent-pattern reports.
- Authority: observe and recommend.
- Limit: does not command critters.
- Stop: escalate only through Echo/Shannon.
- Waste: Squirrel stores institutional learning.

### Squirrel — Interrupt / Continuity / Archive
- Eats: prominent interruptions, snapshots, decisions.
- Produces: pause snapshot, redirect/resume state, archive memory.
- Authority: pause claiming of new work and preserve state.
- Limit: does not decide strategic priority alone.
- Stop: wait for Echo/Shannon resume or redirect.
- Waste: Pantry retains history.

### Dog — Guardian
- Eats: permissions, secret/security events, suspicious behavior.
- Produces: blocks, alerts, boundary reports.
- Authority: stop unsafe operations.
- Limit: cannot initiate projects.
- Stop: escalate uncertain or high-impact security decisions.
- Waste: Hawk/Jane record incidents.

### Bees — Connectors
- Eats: useful outputs and reusable artifacts.
- Produces: cross-project links and reuse suggestions.
- Authority: index and connect.
- Limit: no mutation of source artifacts.
- Stop: do not create duplicate copies without a need.
- Waste: Squirrel/Parts Bin preserve canonical asset.

## Runtime — VERIFIED

The first implemented bounded chain was:

`Owl -> Echo -> Beaver -> Beetle -> Hawk -> Jane -> Harvest`

Its field test reconciled duplicate HQ project records.

The chain was not role-play only:

- Owl produced a bounded evidence/safety packet.
- Echo approved or blocked.
- Beaver created a preview without mutating state.
- Beetle archived originals before applying reconciliation.
- Hawk independently checked remaining duplicates and backup presence.
- Jane recorded handoff/ecology observations.
- Harvest refused completion unless Hawk was GREEN.
- Successful Harvest wrote a reusable Part and a process improvement, then Squirrel recorded the work into memory.

Optional model-backed field notes existed, but the deterministic state transitions and checks did not depend on the model note.

## Self-correction — VERIFIED

v0.6.3 added a real remediation loop:

- If Hawk reports REVIEW, Harvest is blocked.
- Work is routed back to Beaver for remediation.
- After two failed remediation attempts, the work becomes BLOCKED for human review.
- The runtime does not silently widen scope to force success.

This is the historical origin of the self-correcting Habitat concept.

## Recovery objective

The modern Habitat should make this cheap and automatic:

1. New work enters.
2. Search Parts/current products/legacy before building.
3. Reuse existing Parts where possible.
4. Execute bounded work.
5. Verify outcome independently where warranted.
6. Harvest any new/improved Part and process improvement.
7. Connect the Part to all relevant products/machines.
8. Record supersession/retirement without erasing provenance.
9. Preserve enough memory that a future Chief can answer:
   - What is true now?
   - How do we know?
   - What are we trying to do?
   - What must we not accidentally break?

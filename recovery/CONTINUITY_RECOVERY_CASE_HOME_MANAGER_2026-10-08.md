# Connection rule for Cybertron

Recovered records should be modeled as **nodes** with typed evidence edges, not flattened into one remembered story.

Suggested source node fields:

- source_type
- source_date
- stable_identifier if available
- title / human-purpose anchor
- recovered claims
- evidence level
- retrieval query
- independently checkable URL/file reference where available

Suggested edge types:

- `EXPLICITLY_REFERENCES`
- `DERIVED_FROM` — only with direct provenance evidence
- `SEMANTICALLY_MATCHES`
- `SUPERSEDES`
- `CORROBORATES`
- `CONTRADICTS`
- `UNKNOWN_PROVENANCE`

For this case:

`Sep-05 conversation --SEMANTICALLY_MATCHES / UNKNOWN_PROVENANCE--> Sep-23 Home Manager records`

`Sep-23 reconstruction --EXPLICITLY_REFERENCES--> Factory issue #59`

`Sep-23 handoff --EXPLICITLY_REFERENCES--> Factory issue #59`

`Factory issue #59 --HAS_COMMENT--> prior-conversation recovery comment`

No `DERIVED_FROM` edge should be created between the September 5 conversation and issue #59 until stronger evidence exists.
